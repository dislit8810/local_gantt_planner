# Schedule App

個人開発や複数プロジェクトのタスクを、階層型の一覧とガントチャートで管理するローカルWebアプリです。

## ソースコードとタスクデータの分離

- Gitで管理するもの: アプリのソースコード、設定ファイル、ドキュメント
- Gitで管理しないもの: 実際に入力したプロジェクトやタスクのデータ

入力したデータは、アプリ配置先の `data` フォルダに共通JSONとして保存されます。Gitへのコミットやプッシュには含まれません。同じPC上では、ChromeとCodex内ブラウザから同じデータを参照できます。

別PCへの移行やバックアップには、設定画面のJSONエクスポート・インポートを使用できます。

## 必要な環境

- Git
- Node.js LTS版
- Webブラウザ（Chrome、Edgeなど）

## 初回セットアップ

### 1. ソースコードを取得する

```powershell
git clone <リポジトリのURL>
cd ScheduleApp
```

### 2. 必要なパッケージをインストールする

```powershell
npm install
```

### 3. 開発サーバーを起動する

```powershell
npm run dev
```

ターミナルに表示されたローカルURLをブラウザで開きます。通常は次のURLです。

```text
http://localhost:5173/
```

サーバーを停止するときは、起動したターミナルで `Ctrl + C` を押します。

## 2回目以降の起動

```powershell
cd D:\ScheduleApp
npm run dev
```

保存先が異なるPCでは、`cd` のパスをそのPCの配置場所に変更してください。

## 既存環境を最新版へ更新する

古いバージョンを使用しているPCへ、GitHubの最新版を取り込むときの手順です。

### 1. タスクデータをバックアップする

更新前に、アプリの設定画面からJSONをエクスポートしてください。通常、タスクデータはGit管理外の `data` フォルダに残りますが、更新作業中の誤操作に備えてバックアップを推奨します。

### 2. 起動中のSchedule Appを終了する

通知領域の青い「S」アイコンを右クリックして、`Exit`を選択します。コマンドプロンプトから起動している場合は、起動した画面で `Ctrl + C` を押します。

### 3. GitHubの最新版を取り込む

Gitで取得した既存フォルダでは、PowerShellで次を実行します。

```powershell
cd "C:\アプリを配置したフォルダ\local_gantt_planner"
git pull --ff-only origin main
```

ローカルでソースコードを変更している場合は、先にコミットまたは退避してから更新してください。`data`フォルダ内のタスクデータはGitの更新対象外です。

GitHubからZIPをダウンロードし直す場合は、新しいフォルダへ展開してください。古い環境から `node_modules` と `dist` をコピーせず、必要に応じて `data` フォルダだけをバックアップから移します。

### 4. 古い依存パッケージを入れ直す

古い `node_modules` が残っていると、`Cannot find package` や `ERR_MODULE_NOT_FOUND` が発生する場合があります。PowerShellで次を実行してください。

```powershell
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
npm cache verify
npm install
npm run build
```

### 5. 最新版を起動する

`ScheduleAppを起動.vbs` をダブルクリックします。コマンドプロンプトから確認する場合は、次を実行します。

```powershell
npm run dev
```

画面が開いたら、以前のタスクデータが読み込めることを確認してください。読み込めない場合は、新しいデータを入力する前に、手順1で保存したJSONを設定画面からインポートします。

## 動作確認用ビルド

```powershell
npm run build
```

ビルド結果は `dist` フォルダに生成されます。`dist` はGit管理対象外です。

## データ保存の仕様

- タスクデータ: `data` フォルダ内の共通JSON
- スケジュール設定: `data` フォルダ内の共通JSON
- 保存タイミング: 入力・変更時に自動保存
- Gitへの混入: なし
- 複数端末間の同期: なし

初回のみ、旧バージョンのブラウザ保存データを共通JSONへ自動移行します。読み込みに失敗した旧データを上書きで消さない方針を維持します。

### データ互換性

今後のアップデートでは、以前のバージョンで保存したタスクと設定を引き続き読み込める後方互換性を維持します。保存形式を変更する場合は、旧形式から新形式への自動移行処理と、直前バージョンのデータを使った動作確認を必須とします。

## 主な操作

- `Enter`: 次のタスクを作成／編集
- `Tab`: タスクを一階層下げる
- `Shift + Tab`: タスクを一階層上げる
- `Alt + ↑ / ↓`: タスクを並べ替える
- `Shift + クリック`: タスクを範囲選択する
- 範囲選択後の `Tab / Shift + Tab`: 階層を一括変更する
- `Space`: 完了・未完了を切り替える
- `Esc`: 編集を終了する

詳しいショートカットは、アプリ右上の設定画面から確認できます。

## Windowsで簡単に起動する

Node.jsのLTS版をインストールしたあと、`ScheduleAppを起動.vbs` をダブルクリックしてください。初回のパッケージ準備とビルドを自動で行い、黒いコマンド画面を残さず通知領域に常駐します。

通知領域の青い「S」アイコンをダブルクリックすると画面を開けます。右クリックメニューから終了と、Windows起動時の自動起動を切り替えられます。
