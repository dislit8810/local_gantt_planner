# Schedule App

個人開発や複数プロジェクトのタスクを、階層型の一覧とガントチャートで管理するローカルWebアプリです。

## ソースコードとタスクデータの分離

- Gitで管理するもの: アプリのソースコード、設定ファイル、ドキュメント
- Gitで管理しないもの: 実際に入力したプロジェクトやタスクのデータ

入力したデータは、ブラウザの `localStorage` に保存されます。Gitへのコミットやプッシュには含まれません。

データは「使用するPC・ブラウザ・URL」の組み合わせごとに別管理です。別のPCでアプリを起動しても、元のPCのタスクデータは自動では移りません。ブラウザのサイトデータを削除するとタスクも消えるため、将来的にはエクスポート・インポート機能を追加する予定です。

## 必要な環境

- Git
- Node.js LTS版
- pnpm
- Webブラウザ（Chrome、Edgeなど）

## 初回セットアップ

### 1. ソースコードを取得する

```powershell
git clone <リポジトリのURL>
cd ScheduleApp
```

### 2. pnpmを準備する

Node.jsをインストールしたあと、pnpmが使えない場合は次を実行します。

```powershell
npm install --global pnpm
```

### 3. 必要なパッケージをインストールする

```powershell
pnpm install
```

### 4. 開発サーバーを起動する

```powershell
pnpm run dev
```

ターミナルに表示されたローカルURLをブラウザで開きます。通常は次のURLです。

```text
http://localhost:5173/
```

サーバーを停止するときは、起動したターミナルで `Ctrl + C` を押します。

## 2回目以降の起動

```powershell
cd D:\ScheduleApp
pnpm run dev
```

保存先が異なるPCでは、`cd` のパスをそのPCの配置場所に変更してください。

## 動作確認用ビルド

```powershell
pnpm run build
```

ビルド結果は `dist` フォルダに生成されます。`dist` はGit管理対象外です。

## データ保存の仕様

- タスクデータ: ブラウザのローカル保存
- スケジュール設定: ブラウザのローカル保存
- 保存タイミング: 入力・変更時に自動保存
- Gitへの混入: なし
- 複数端末間の同期: なし

同じPCでも、別ブラウザや異なるポートで開くと別データとして扱われる場合があります。普段は同じブラウザで `http://localhost:5173/` を使用してください。

### データ互換性

今後のアップデートでは、以前のバージョンで保存したタスクと設定を引き続き読み込める後方互換性を維持します。保存形式を変更する場合は、旧形式から新形式への自動移行処理と、直前バージョンのデータを使った動作確認を必須とします。

## 主な操作

- `Enter`: 次のタスクを作成／編集
- `Tab`: タスクを一階層下げる
- `Shift + Tab`: タスクを一階層上げる
- `Alt + ↑ / ↓`: タスクを並べ替える
- `Shift + クリック`: タスクを範囲選択する
- 範囲選択後の `Tab / Shift + Tab`: 階層を一括変更する
- `Space`: 完了・未完了を切り替える
- `Esc`: 編集を終了する

詳しいショートカットは、アプリ右上の設定画面から確認できます。
